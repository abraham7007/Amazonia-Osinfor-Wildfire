# Documento de Control de Interfaces (ICD)

| Estado | Fecha |
|---|---|
| Borrador | 2026-06-11 |

> **Propósito.** Define las interfaces entre bloques: eléctricas, de datos y mecánicas.

## Qué documentar aquí

- Interfaz cámara ↔ MCU (CSI / SCCB / I2C)
- Interfaz MCU ↔ radio LoRa (SPI/UART)
- Interfaz energía (conectores, tensiones, fusibles)
- Interfaz nodo ↔ gateway (parámetros LoRaWAN)
